# Media Guidelines for Fixnero Website

## Overview
This document provides guidelines for creating, optimizing, and using visual content on the Fixnero website to enhance user experience, improve SEO, and drive conversions.

## Photo Requirements

### Technical Specifications

**General Photos**:
- Format: JPEG (for photos), PNG (for logos/graphics), WebP (recommended for web)
- Size: Maximum 2MB per image
- Dimensions: 1920x1080px (landscape), 1080x1350px (portrait)
- Quality: 85% compression for web use
- Color: sRGB color space

**Service Pages**:
- Hero Images: 1920x800px minimum
- Before/After: 800x600px minimum
- Thumbnails: 400x300px
- Icons: 200x200px (PNG with transparency)

**Mobile Optimization**:
- Separate mobile versions: 768px wide maximum
- Lazy loading enabled
- Alt text required for all images

## Image Optimization

### Pre-Upload Checklist

1. **Resize images**
   ```
   Desktop: Max 1920px wide
   Mobile: Max 768px wide
   Thumbnails: Max 400px wide
   ```

2. **Compress images**
   - Use tools: TinyPNG, ImageOptim, Squoosh
   - Target: <200KB for most images
   - Quality: 80-85% for photos

3. **Format conversion**
   - Convert large PNGs to JPEG
   - Consider WebP for better compression
   - Keep PNG for logos/transparency

4. **Add metadata**
   - Alt text: Descriptive, includes keywords
   - Title: Brief, relevant
   - Caption: Context if needed

### File Naming Convention

**Format**: `category-description-size.extension`

**Examples**:
- `before-after-car-wash-dirty-sedan.jpg`
- `service-tire-change-process.jpg`
- `testimonial-customer-happy.jpg`
- `facility-exterior-winter.jpg`
- `result-polished-bmw-hero.jpg`

**Rules**:
- Lowercase only
- Hyphens instead of spaces
- Descriptive keywords
- No special characters
- Include size indicator if multiple versions

### Alt Text Guidelines

**Purpose**: Accessibility, SEO, context when image fails to load

**Good Alt Text Examples**:
- ✅ "Fixnero technician applying ceramic coating to black sedan in Espoo"
- ✅ "Before and after car interior cleaning showing leather seats transformation"
- ✅ "Winter tire change service in progress at Fixnero auto shop"
- ✅ "Customer car freshly washed and polished in Kivenlahti, Espoo"

**Bad Alt Text Examples**:
- ❌ "Image1.jpg"
- ❌ "Car"
- ❌ "Photo"
- ❌ "IMG_2023.jpg"

**Alt Text Formula**:
```
[Action/Subject] + [Details] + [Location if relevant]
```

## Photography Tips

### Equipment
**Minimum**:
- Smartphone with good camera (iPhone 11+, Samsung S20+)
- Good lighting (natural daylight preferred)
- Stable surface/tripod

**Ideal**:
- DSLR or mirrorless camera
- Lighting kit (for interior/detail shots)
- Tripod
- Photo editing software (Lightroom, Photoshop)

### Composition
**Rule of Thirds**:
- Important elements on intersections
- Horizon on top or bottom third line

**Leading Lines**:
- Use car lines to guide eye
- Driveway, garage lines

**Before/After**:
- Same angle, same framing
- Split screen or side-by-side
- Clear difference visible

### Lighting
**Best Conditions**:
- Natural daylight (avoid harsh noon sun)
- Overcast days (even, soft light)
- Golden hour (morning/evening)

**Avoid**:
- Direct harsh sunlight (creates glare)
- Mixed lighting (fluorescent + natural)
- Too dark (underexposed)

### Backgrounds
**Good**:
- Clean, uncluttered
- Neutral colors
- Professional environment
- Natural settings

**Avoid**:
- Messy workshop
- Distracting elements
- Personal items
- Competitors' branding
