Testing Instructions

  1. Chrome DevTools: Press F12 → Toggle Device Toolbar (Ctrl+Shift+M)
  2. Select Device Presets:
    • Samsung Galaxy Tab A8 (or set custom: 1920x1200)
    • iPad Air (820x1180)
    • iPad Pro 12.9" (1024x1366)
    • Laptop with 15" (set custom: 1920x1080, pointer: fine)
  3. Verify: The appropriate scaling indicator should highlight in green
  4. Check: Content should be appropriately sized for each device

Expected Results:

  • Samsung A8 (1920x1200): Font-size = 13.6px (85% of 16px base), sections narrower
  • iPad Air: Font-size = 14.4px (90% of 16px base)
  • iPad Pro: Font-size = 16px (100%)
  • Laptop: Font-size = 16px (100%), no tablet-specific rules apply
